# 🎵 AR Player

> Reproductor ligero para Android con soporte para descarga de listas de reproducción de Youtxbx SIN PUBLICIDAD :-).

---

## 📲 Descargar para Android
Obtén la última versión estable directamente en tu móvil sin necesitar cuenta en GitHub:

[![Descargar APK](https://shields.io)](https://github.com)

*(También puedes abrir la [página de la versión v1.0.0](https://github.com/aRedondoH/mi-reproductor-yt/releases/tag/v1.0.0) para elegir el archivo).*


### Cómo instalarla
1. Pulsa el botón verde **Descargar APK** (la descarga empezará al instante).
2. Abre el archivo `mi-reproductor-yt.apk` desde tus notificaciones o desde tu gestor de archivos.
3. Si Android muestra un aviso de seguridad, pulsa **Configuración** y activa **Permitir desde esta fuente**.
4. Toca **Instalar** y listo.

## ✨ Características principales

* 🎧 **Audio en segundo plano:** Sigue escuchando con la pantalla apagada o usando otras apps.
* 🎬 **Reproducción de vídeo:** Soporte integrado para contenido multimedia.
* 🔔 **Notificaciones y controles:** Gestiona la reproducción desde la barra de notificaciones.
* ⚡ **Compilación nativa:** Optimizado para dispositivos Android modernos (`arm64-v8a`).

## 🛠️ Tecnologías utilizadas

* **[Flet](https://flet.dev):** Interfaz de usuario multiplataforma desarrollada en Python.
* **Flutter & Android SDK:** Empaquetado nativo para Android.
